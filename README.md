<p align="center"><img src="docs/gif/backup.gif" alt="Back up your game first: copy Data, Data-1.13 and SavedGames somewhere safe" width="880"></p>

> [!IMPORTANT]
> **Back up your game before using the editor!**
> The editor changes saves, game data and maps directly on disk, and there is always a chance it **damages your game files**. Before you start, copy your whole game folder (at least `Data`, `Data-1.13` and `SavedGames`) somewhere safe — just in case. The editor's own `.bak` copies and save history help, but they do not replace a full backup of your own.

### 🔨 How to build

1. **Get the source code.** It ships with the editor: ⚙ → Web developing → **Unpack the source code next to the app** (an `app` folder with `ja2-editor`, `desktop` and `installer`) or **Download the source code (.zip)**. The same source is attached to every [release](../../releases/latest) as `app.zip`.
2. **Run it without building.** Install [PHP](https://www.php.net/downloads), then in the `ja2-editor` folder run `php -S 127.0.0.1:8080` and open `http://127.0.0.1:8080` in a browser.
3. **Build the Windows app.** Install [Go](https://go.dev/dl/) and build the program in the `desktop` folder (`go build`). The app shows the editor in a [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) window, so the WebView2 Runtime must be on the computer (Windows 10 and 11 normally have it).
4. **Build the setup and the portable zip.** Install [NSIS](https://nsis.sourceforge.io/Download) and compile the script in the `installer` folder with `makensis`.
5. **Texts for translators.** `en.json` is made from the editor's own scripts and pages by `tools/i18n-extract.js` each time the app is built.

The exact commands, options and tool versions are in `HOW TO BUILD.txt`, which lies in the `app` folder next to the source code (also inside `app.zip`).

<details>
<summary>📋 <b>Full feature list</b> (20)</summary>

- **Loading screen:** work that takes more than a moment (reading the game data, checking everything, reading many saves or maps) shows a screen over the whole window with what is being done and the per cent; a question or an error that comes up meanwhile is never covered. Dialogs all behave the same: they hang from the same place, always fit the window (the title and buttons stay in view, the body scrolls inside), and the page behind does not move or scroll while one is open.
- **Game folder** — type or Browse to the folder with ja2.exe and press Connect (in the Windows app the only way in; it reads and writes on disk); all data (items, pictures, maps, saves) is read from it. Settings are kept in `%APPDATA%\Jagged Alliance 2 - Game Editor`. Start screen with a loading bar from the moment the app opens (in the Windows app drawn by the window itself before the page has loaded) and while the folder is read. - **Game data → More → Scripts → GameInit.lua of UB:** Enemies at the start of a UB campaign — every sector's administrators, troops and elites per difficulty as a form (“a + b” is a plus 1 to b at random), written into the script in place (UB_SetNumberJa25EnemiesInSurfaceSector). At most 50 of a kind and the random part up to 30 (the game adds the three into one byte).
- **The counter-attacks of UB as 1.13 is built:** the game's choice of the sector to attack (GetSectorJa25SaiWillAttack) was emptied and reports sector −1, so the game looks before the start of the table and never uses any of its sectors — these numbers change nothing; the story dialog says so and keeps the numbers editable for a build that brings it back. The early attack on the landing sector is a separate event and works.
- **UB maps:** only about 37 (H7–L15 and their levels, a few more from Data-1.13) — all of them are read and written, also the five in the old 6.26 format (I13, I10A, I13_B1, J13_B1, K16), which keep that format: UB's set of folders (vfs_config.UB113.ini) leaves the JA2 maps library out, so most of the Tracona grid is empty. To work on another sector there, bring its map over with A sector from the other game or make one with Generate a sector…. The maps are drawn the way the UB game draws them: UB's own tilesets (50 and up) take the pictures they lack from tileset 50 (heavy snow), not from tileset 0.
- **Gear kits in a UB save:** the nineteen kits take what UB's Items.xml has (with attachments, plates, camouflage on the armour, packs and filled pockets as in JA2), for your mercs and for the militia and the soldiers on the loaded map of Tracona, also in the middle of a battle.
- **Doors: locks and traps and Campaign statistics** work in a UB save the same way.
- **More save tools in a UB save:** Move a squad (only to sectors of the UB campaign that have a map of that level), Plan a trip (on foot — UB has no cars and no Skyrider; the ways between the sectors are the ones the save itself keeps, so a sector outside the campaign cannot be entered), Send a group at the squad (the group's new way is the shortest one over those ways, a waypoint in every sector; a group already on the way starts from the sector it is heading for), Where to sell the loot (only the dealers who stand in Tracona — Raul and Betty), Money: the next days, Life insurance (with a note: UB shows the insurance site only when LINK_INSURANCE is on in UB_Options.INI; a payout comes either way, the letters do not), What next in the quests (UB's own quests, without Arulco's notes), Presets, Reveal the map (the enemy numbers in the sectors of the campaign; Tixa, Orta and the SAM sites are Arulco's and are left alone), Free prisoners (in UB the enemy takes none, and this is said) and Town… on the Towns view (Varrez: its sectors, militia, dealers and people). The sectors you hold are counted out of UB's own sectors, and the game's status block (kills, deaths, days without a fight) is read in a UB save too.
- **UB scripts:** strategicmap.lua as a form — the sector and level each piece of its quest code is tied to (entering I10 makes Tex and Betty known, leaving H7 takes Jerry off the map); the same form shows for Jagged Alliance 2. Three scripts UB keeps as empty shells (InterfaceDialogue.lua, StrategicEventHandler.lua, MakeMapsOnHardDrive.lua) are said to do nothing in this game and are not counted in What the editor covers; intro.lua is edited as text.
- **Behind the scenes and What the sectors keep** work in a UB save too (UB's own sizes of the blocks; the map-change kinds of UB), and the INI files of UB show their own notes and group notes the same way — every setting explained.
- **Your reputation, Intel and militia resources, The queen's forecast and Bobby Ray's shopping list** work in a UB save too (checked by loading the changed save in Unfinished Business itself); the shopping list says when UB_Options.INI leaves Bobby Ray's off the laptop. The PMC, the intel market, the special division, Rebel Command and the generals and militia orders are not used by Unfinished Business and say so.
- **UB scripts as forms:** the bloodcats of a sector by difficulty (InitStrategicLayer.lua, UB_SetNumberOfJa25BloodCatsInSector), what dealers sell for intel (Overhead.lua), the loyalty after an event, the names of the underground levels — besides the enemies of GameInit.lua and initunderground.lua.
- **999 action points for everyone in the battle** (Squad menu) and the lip-sync of the voice lines work in UB the same way, on UB's Speech files.
- **Many new mercs…** writes UB's MercProfiles25.xml; What the editor covers… measures UB's own folders; the ten tables of More (soldier names, remarks, random stats, food, face gear, uniforms, delivery, objects to use, fortifications, shot spread) are read where UB's set of folders finds them.
- **Everything else** — maps, items and their pictures, sounds, dialogue, settings, the mercs' tables — works for UB the same way, with the UB data.

## Getting started

<p align="center"><img src="docs/gif/getting-started.gif" alt="Five steps: download, scan, back up, run, connect" width="880"></p>

1. [Download the latest release](../../releases/latest) and unpack it.
2. **Scan the files for viruses** (see the links above).
3. **Back up your game folder and saves** — the editor can damage game files.
4. Run `ja2-game-editor.exe`.
5. Type or *Browse* to your game folder (the one that contains `ja2.exe`) and press **Connect**.

### Verify the download (SHA-256)

Every release lists the SHA-256 checksum of its files. Download the editor **only from this repository** and compare the checksum before running it.
In PowerShell, in the folder with the downloaded file:

```powershell
Get-FileHash .\ja2-game-editor.exe -Algorithm SHA256
```

or in the Command Prompt:

```bat
certutil -hashfile ja2-game-editor.exe SHA256
```

If the value differs from the one in the release notes, **do not run the file** — it was changed by someone else.

## Troubleshooting / FAQ

<p align="center"><img src="docs/gif/faq.gif" alt="Troubleshooting / FAQ" width="880"></p>

**Windows SmartScreen says "Windows protected your PC".**
Windows shows this for new programs downloaded from the internet that it does not know yet. Check the file with the scanners and the SHA-256 checksum above, then press *More info* → *Run anyway*.

**Connect does not work / the game folder is not found.**
Pick the folder that contains `ja2.exe` itself, not a folder above it or a shortcut. If the game is in `Program Files`, Windows may block writing there — move the game to another folder (for example `C:\Games\JA2`) or run the editor as administrator.

**Something went wrong after an edit — how do I undo it?**
Every file the editor writes keeps the original next to it as a `.bak` copy: delete the edited file and remove `.bak` from the copy's name.
For saves it is even easier: *Save list* → *Save history* keeps the last 30 versions of each save — pick one and *Restore*.

**Where are my editor settings?**
In `%APPDATA%\Jagged Alliance 2 - Game Editor`. Delete that folder to reset the editor to defaults.

## Reporting bugs

<p align="center"><img src="docs/gif/report-bug.gif" alt="Reporting bugs: Report a problem, .zip with log and save, attach to an Issue" width="880"></p>

Found a bug or have an idea? The quickest way: in the editor open **⚙ → Report a problem…** — it packs the details, the log and (if you tick them) the open save, map and `Ja2_Options.INI` into one `.zip` and opens the [Issues](../../issues) page to attach it. Otherwise open an [issue](../../issues) and include:

- the editor version and your game version (and any mods you use);
- what you did, what you expected and what happened instead;
- a screenshot, and the save or data file if the problem is with one.
